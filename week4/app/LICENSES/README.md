# Font licences bundled with the Week 4 app

The host embeds IBM Plex Sans, IBM Plex Mono and Space Grotesk through the `@fontsource/*` npm packages (SIL Open Font License 1.1). The licence texts here are copied verbatim from those packages so they travel with any built `dist/` output (AGENTS.md: bundle font licences with assets when implementation starts).
