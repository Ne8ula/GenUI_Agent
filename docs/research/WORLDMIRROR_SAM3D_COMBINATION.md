Use SAM 3D Objects only for incomplete objects that have sufficient photographed evidence and reliable cross-view identity. Keep the existing one-room boundary, raw reconstruction and [general completion requirements](GENERAL_ROOM_COMPLETION.md).

Use `worldrecon`; the separate panorama/world-expansion pipeline is unnecessary for this proposal. [Official repository](https://github.com/Tencent-Hunyuan/HY-World-2.0).

## Proposed flow

1. Admit the same 5–7 original photos. Run WorldMirror and retain source-linked cameras, geometry and preprocessing transforms. Compare against VGGT before selecting a room estimate.
2. Detect and mask objects automatically using the existing Grounding DINO/SAM 2 stage. Associate identities across views conservatively; ambiguous associations require correction.
3. Identify incomplete objects from visibility, mask truncation and geometric support. Select a useful source view for each object. A missing detection must not create default furniture.
4. Supply the selected original image, mask and converted point map to SAM 3D. Generate one object candidate per identity; use the other photos to validate its visible shape and placement.
5. Fit the candidate to reliable visible support, check projected silhouettes with occlusion handling, floor/support contact, wall penetration and room containment. Reject conflicting candidates instead of forcing a flat bridge between fragments.
6. Keep the raw estimate immutable. In the aesthetic candidate, replace the corresponding fragmented object with one accepted coherent object, avoiding duplicate layers. Preserve observed-source links while labeling the generated mesh as inferred.
7. Sample the accepted geometry for EVA's Paris matrix/uniform dots. Retain photo colors and hollow marks for inferred geometry. Close architectural openings only within the reviewed room; never expand into adjoining rooms.

Steps 2–7 are an EVA integration proposal, not capabilities supplied automatically by either model. In particular, the [SAM 3D paper, Appendix F](https://arxiv.org/html/2511.16624v1) states that object predictions do not jointly reason about contact, stability, interpenetration or co-alignment. Those require explicit downstream checks.

## Coordinate and evidence contract

WorldMirror exports world-space points and OpenCV camera-to-world poses; depth is camera Z-depth. Its arrays include batch and view dimensions. [Output documentation](https://github.com/Tencent-Hunyuan/HY-World-2.0/blob/main/DOCUMENTATION.md).

SAM 3D's external point-map path expects a tensor and bypasses its internal depth estimator. Its code handles point maps in a camera convention that needs conversion; do not pass WorldMirror world-space points directly. Match the selected image's pixels, resize/crop and camera frame, then convert axes using the inspected implementation. Preserve a reversible transform back to EVA coordinates and verify it with projection tests. [Point-map implementation](https://github.com/facebookresearch/sam-3d-objects/blob/main/sam3d_objects/pipeline/inference_pipeline_pointmap.py).

An uncertain area such as “around 300 sqft” is a weak scale prior, not measured dimensions. Multi-view consistency and attractive hidden geometry do not prove physical accuracy. If the selected photos never establish whether two fragments belong to the same object, retain that uncertainty.
